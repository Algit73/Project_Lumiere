# URP Material Upgrader

## Problem
After enabling the Universal Render Pipeline (URP) in the project, materials using the Built-in Render Pipeline's Standard shader appear pink/magenta because those shaders are incompatible with URP.

Additionally, FBX models (like Kenney kits) may have embedded materials that also need extraction and upgrading.

## Solution
This tool automatically scans your project for materials using incompatible Built-in shaders and upgrades them to URP equivalents.

## How to Use

### For Kenney Food-Kit DAE Models (Pink Materials)

**If your DAE models (in `DAE format` folder) appear pink:**

1. **Open Unity Editor**
2. **Go to Menu**: `Tools > URP Material Upgrader`
3. **Click**: "Fix DAE Materials (Kenney Food-Kit)"
4. Wait for the process to complete (it will re-import all DAE files and upgrade their materials)
5. **Done!** All DAE models should now render correctly

### For FBX Models with Embedded Materials

1. **Open Unity Editor**
2. **Go to Menu**: `Tools > URP Material Upgrader`
3. **Click**: "Extract & Scan FBX Materials" (This will extract embedded materials from FBX files and scan them)
4. **Review**: The list of materials that will be upgraded
5. **Click**: "Upgrade All Materials to URP"

### For Regular Materials

1. **Open Unity Editor**
2. **Go to Menu**: `Tools > URP Material Upgrader`
3. **Click**: "Scan for Incompatible Materials"
4. **Review**: The list of materials that will be upgraded
5. **Click**: "Upgrade All Materials to URP"

## What Gets Upgraded

The tool will upgrade:
- Standard shader → URP/Lit
- Standard (Specular) → URP/Lit
- Mobile shaders → URP/Simple Lit
- Unlit shaders → URP/Unlit
- Unlit/UnlitColor → URP/Unlit
- UnityChan Toon Shader → URP/Lit (with warning)
- Legacy shaders → URP equivalents

## Embedded Materials (FBX Models)

Many 3D model packs (like Kenney kits) have materials embedded inside the FBX files. 
These don't show up as separate `.mat` files and can't be directly upgraded.

The "Extract & Scan FBX Materials" button will:
1. Find all FBX files in `Assets/Models`
2. Extract embedded materials to external `.mat` files
3. Create a `Materials` folder next to each FBX file
4. Automatically scan the extracted materials for upgrading

**Note**: This changes the FBX import settings to use external materials permanently.

## DAE Materials (Collada Format)

DAE files from some asset packs (like Kenney food-kit) may be configured to use external materials that don't exist, causing pink rendering.

The "Fix DAE Materials" button will:
1. Find all DAE files in `Assets/Models`
2. Change them to use embedded materials (generated by Unity from DAE data)
3. Re-import all DAE files
4. Automatically upgrade embedded materials to URP shaders

**Why DAE files appear pink:**
- DAE import settings may reference external `.mat` files that were never created
- When materials are missing, Unity shows pink/magenta
- Solution: Use embedded materials which Unity generates automatically from DAE color/texture data

## What Gets Preserved

The tool will NOT modify:
- Custom shaders (Toon, AnimeGirls shaders, etc.)
- TextMesh Pro materials
- Plugin materials (CW/Lean)
- Sample materials
- Materials already using URP shaders

## Property Mapping

The tool preserves material properties:
- `_Color` → `_BaseColor`
- `_MainTex` → `_BaseMap`
- `_BumpMap` → `_BumpMap` (same)
- `_Metallic` → `_Metallic` (same)
- `_Glossiness`/`_Smoothness` → `_Smoothness`

## Undo Support

All changes are recorded in Unity's Undo system, so you can undo the upgrade if needed (Ctrl+Z).

## Notes

- Custom shaders (like Toon shaders) may need manual URP conversion if they appear pink
- If custom shaders appear pink, contact the shader author for URP-compatible versions
- The upgrade is non-destructive and can be undone
